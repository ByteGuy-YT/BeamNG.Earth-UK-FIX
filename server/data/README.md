# UK rule boundaries

`uk_countries_2024.geojson.gz` contains the four unmodified WGS84 geometries from ONS
Countries (December 2024) Boundaries UK BGC, generalised to 20 m and clipped to the coastline.
Only the feature properties were reduced to the country name. Gzip is deterministic.

Downloaded 2026-10-20 from:
https://services1.arcgis.com/ESMARspQHYMw9BZ9/arcgis/rest/services/Countries_December_2024_Boundaries_UK_BGC/FeatureServer/0/query?where=1%3D1&outFields=*&outSR=4326&f=geojson

Source documentation and licensing:
